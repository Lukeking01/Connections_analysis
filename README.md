### Reproducibility

The dataset can be regenerated using `Scraper.py`. Because the upstream
website and its available data may change over time, regenerated datasets
may not be byte-for-byte identical to previously collected versions.

When publishing results based on this dataset, please identify the source,
the date on which the data was collected, and the version of the analysis
code used.
